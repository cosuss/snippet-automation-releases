# Snippet Automation 다운로드

[다운로드 페이지](https://cosuss.github.io/snippet-automation-releases/) · [최신 설치 파일](https://github.com/cosuss/snippet-automation-releases/releases/latest)

이 저장소는 설치·업데이트 파일과 다운로드 안내만 배포합니다. 개발 소스 저장소는 비공개로 유지합니다.

- Windows x64: 앱 안에서 자동 다운로드, 자동 설치 또는 일시 예약을 설정합니다.
- Apple Silicon Mac: 현재는 서명 준비 전 테스트 설치 파일입니다. Mac 자동 업데이트는 Developer ID로 서명한 버전부터 제공할 수 있습니다.
- 기존 0.3.0 사용자는 업데이트 기능을 포함한 새 버전을 한 번 설치해야 합니다.

자동·예약 설치는 앱이 실행 중이고, PC를 5분 이상 사용하지 않고, 저장할 내용과 진행 중인 작업이 없을 때 재시작합니다. 예약 일시는 해당 업데이트 한 번에 적용됩니다.

Windows의 실제 설치 교체와 Mac의 서명·공증을 거친 자동 업데이트는 추가 검증이 필요합니다. 현재 배포는 테스트용입니다.
