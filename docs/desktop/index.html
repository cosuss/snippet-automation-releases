Mac

Apple Silicon Mac용 앱입니다. Sparkle을 내장하여 새 버전을 자동 다운로드하고, 앱 안에서 자동 설치 또는 예약 일시를 선택할 수 있습니다.

Mac 테스트 버전 다운로드 ↗ DMG 설치 파일 · Apple Silicon / Intel Mac 미지원

설치한 다음부터는 앱 안에서

  1. 앱 상단의 업데이트를 엽니다.
  2. 자동 업데이트 또는 업데이트 일시 선택을 저장합니다.
  3. 새 버전은 자동 다운로드하고, 준비된 시점에 앱을 재시작해 설치합니다.

자동·예약 설치는 앱이 실행 중이고 PC를 5분 이상 사용하지 않으며, 저장할 내용과 진행 중인 작업이 없을 때 진행합니다. 예약 시각에 앱이 꺼져 있으면 다음 실행 후 설치합니다. 예약 일시는 해당 업데이트 한 번에 적용됩니다. 저장된 자료와 연결 설정은 유지됩니다.

기존 사용자를 위한 안내

Mac 0.4.1 이하·Windows 0.3.0 이하 사용자는 업데이트 기능이 포함된 새 버전을 한 번 설치해 주세요. 이후에는 앱 안에서 업데이트하므로 설치 파일을 직접 다시 받을 필요가 없습니다. Mac은 DMG를 열고 앱을 응용 프로그램 폴더로 옮겨 실행하세요.

Mac 최초 실행 시 개발자 확인 경고가 나오면 macOS 시스템 설정 → 개인정보 보호 및 보안에서 이 앱의 실행을 허용해야 할 수 있습니다. Apple 서명·공증을 받은 앱은 아니며, 업데이트에는 별도의 서명 검증을 사용합니다. 앱·OS 정책에 따라 기존 접근 권한을 다시 허용해야 할 수 있습니다.

Mac의 실행 중 앱 교체·재시작, 테스트 기록과 암호화 키 보존, 변조 파일 거부를 확인했습니다. Windows 실제 PC의 설치 교체와 다른 Mac의 권한 유지는 추가 검증이 필요합니다. 스니펫 작성·평가에는 본인 AI 연결이 필요합니다.
